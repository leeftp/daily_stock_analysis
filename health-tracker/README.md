# 2週間 体調記録アプリ

睡眠・物忘れ・仕事のミス・疲労感・気分・性欲/朝立ち・飲酒量を、**14日間だけ**かんたんに記録するためのアプリです。記録を忘れないように**毎日リマインド**できます。

- インストール・アカウント登録・サーバー不要（HTMLファイル1つだけ）
- データは**端末のブラウザ内だけ**に保存（外部送信なし）
- スマホ・PCどちらでも使えます

## 記録する項目

| 項目 | 入力方法 |
| --- | --- |
| 😴 睡眠時間 | 時間（例 6.5）＋ 就寝・起床時刻（任意） |
| 🧠 何を忘れたか | 自由記述 |
| 💼 仕事のミスの内容 | 自由記述 |
| 🔋 疲労感 | 0〜5 の6段階 |
| 🌧 気分の落ち込み | 0〜5 の6段階 |
| 🌅 性欲・朝立ちの変化 | 選択（増えた〜ほぼない）＋ メモ |
| 🍶 飲酒量 | 量（缶/杯/合など）＋ メモ |

## 使い方

### 1. 開く
`index.html` をスマホやPCのブラウザで開くだけです。

- **スマホ（推奨）**: ファイルを開いたあと、ブラウザのメニューから「**ホーム画面に追加**」しておくと、アプリのように毎日すぐ開けます。
- 公開して使いたい場合は、GitHub Pages などの静的ホスティングにこのフォルダを置けばURLで開けます。

### 2. 記録する
- 上部の `‹ › ` で日付を移動できます（その日の朝・夜どちらでもOK）。
- 入力して「**💾 この日を保存**」を押すだけ。あとから修正もできます。
- 進捗バーと14個のマスで「あと何日記録したか」がひと目で分かります。

### 3. 毎日リマインドを受け取る（2通り、併用推奨）

1. **📱 端末で通知をオン**
   通知時刻を設定して「この端末で通知をオンにする」を押します。
   アプリ（この画面）を開いている／ホーム追加した状態のときに、その時刻にお知らせします。

2. **📅 カレンダーに追加（.ics）— 確実に毎日鳴らしたい人向け**
   「14日分の毎日リマインドを追加」を押すと `.ics` ファイルがダウンロードされます。
   これをスマホの**カレンダーアプリで開く（取り込む）**と、14日間・毎日同じ時刻に
   スマホ標準の通知が出ます。アプリを閉じていても鳴るので確実です。

> ブラウザだけの通知は、OSやブラウザの仕様でアプリを閉じていると鳴らないことがあります。
> 「絶対に忘れたくない」なら **.ics（カレンダー）取り込み**を使ってください。

### 4. 書き出し（医師に見せる・保管する）
「📤 データの書き出し・確認」を開くと、

- **CSVダウンロード**（Excel等で開けます）
- **テキストでまとめてコピー**（メッセージに貼り付け）
- **全データ削除**

ができます。

## よくある質問

- **データはどこに保存される？** お使いの端末・ブラウザの中（localStorage）だけです。サーバーには送りません。
- **記録期間はいつから？** 初めて開いた日が1日目になり、そこから14日間です。
- **端末を変えると引き継げる？** 自動同期はありません。CSVやテキストで書き出して移してください。
- **キャッシュ削除でデータは消える？** ブラウザのサイトデータを消すと記録も消えます。大事な記録はCSVで保存を。

## 技術メモ

- 依存ライブラリ・ビルド工程なしの単一 `index.html`（バニラ HTML/CSS/JS）。
- リマインドは Web Notification API（前面時）＋ iCalendar(.ics) の `RRULE:FREQ=DAILY;COUNT=14` を生成。
- 株価分析システム本体とは独立した自己完結アプリで、既存のバックエンド/通知基盤には依存しません。
